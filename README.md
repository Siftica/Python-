# 大模型原理与工程实践

面向希望理解大模型并亲手实现相关系统的学习者，结合概念讲解、代码实验与项目实践，连接模型原理和工程实现。适合从 Python 基础起步，也适合希望补足原理与实践环节的开发者。

## 学习范围

- **基础能力：** Python、必要数学、数据处理、PyTorch 与训练流程。
- **模型原理：** 分词、Transformer、注意力机制、公开模型架构与微调。
- **工程应用：** 执行推理（inference）、逻辑推理（reasoning）、代码生成与测试、RAG、agent 和工具调用。

课程目标包括解释数据流与张量形状、理解训练目标、实现可复用模块，并通过对照实验判断方法效果。上述内容是项目的课程范围，材料逐步完善，以目录中的实际文件为准。

## 材料组织

课程文件位于 `lessons/`。每课采用两种配套形式：`.ipynb` 提供分步解释、实验与练习；同名 `.py` 提供可以独立运行的完整示例。Notebook 适合边读边改，脚本适合观察完整执行流程和继续扩展。

建议先预测输出，再运行、修改输入并独立完成变化题。代码示例以便于理解和修改为优先，逐步过渡到有配置、评测与错误处理的小型项目。

## 快速开始

准备好 Python 3 环境，在项目根目录运行入门示例：

```bash
python lessons/lesson_01_text_to_ids.py
```

阅读 Notebook 时，可在所用 Python 环境中安装并启动 JupyterLab：

```bash
python -m pip install jupyterlab
python -m jupyterlab
```

在浏览器中打开 `lessons/` 下的讲义。根据本机安装情况，命令中的 `python` 可替换为 `python3` 或 `py`。

## 实践环境

Python 入门示例可以使用 CPU，独立脚本仅依赖内置功能与标准库。进入 PyTorch 和模型实验后，再安装相应依赖，并根据显存、上下文长度和任务调整模型与训练规模。

项目采用“小模型实现机制、公开资料理解主流模型、固定任务评测系统”的实践方式，不要求本地运行所有大模型。学习产物从文本处理程序逐步发展为模型实验、检索流程和可评测的智能助手。
